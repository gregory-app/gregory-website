What Gregory does

In the model. Not a chat you paste a file into.

Gregory is already on the cell, with the workbook open. Ask it there. The same question works from Claude or ChatGPT — it reads what is signed, and it still cannot write the model.

Ask

On the cell you have open

Ask Gregory about this cell, or under the drivers that move an output. It opens on what the cell is, whether it is signed, what it feeds, and what to check. A figure the record does not hold is withheld.

Read

The call, the email, the file

A transcript, a contract, an export. Gregory reads them and proposes the change, with the quote beside it. Fill with Gregory drafts the source into the signature. What it cannot ground, it flags.

Sign

The answer you keep

The inputs that move the output are the ones that get a signature — who, when, from what, and what it replaced. Stale is one click: Still true? The AI proposes. You decide. Nothing reaches the cell until you say so.

Sources

Said on a call, held to the same standard.

A deposit agreed out loud, a term in a contract, a line in an email. Gregory reads them beside the exports, and a proposed number has to point at the words it came from.

A question

From asking the cell to a number you can defend.

Ask, on the cell. What it is, where it stands, what it feeds, what moves the output. Gregory speaks first, from the model in front of you.

It answers from the record. The file, the call, the email, the signature. A number it cannot point at is withheld, not invented.

A reply becomes proposed changes. The transcript, the contract, the PDF. Each value carries the quote it came from. What cannot be grounded is flagged.

You sign what moves the answer. Approve, edit, or reject. Stale is “Still true?”. Approved changes are applied with a snapshot before and after.

The file still opens. The last signature travels as a note and a hidden sheet. No macros. Remove Gregory and the model still opens.

Non-negotiables

Product rules, enforced in code.

Nothing writes without approval.

The only path that changes a workbook runs through changes a person decided. There is no auto-apply, and no way around the gate.

The workbook stays yours.

What Gregory leaves in the file uses native features — named ranges, notes, a hidden sheet. No macros, and no add-in required to open it.

Excel in, Excel out. Sheets in, Sheets out.

A model lives on one platform for its whole life. Gregory never converts the file into something the client cannot open.

No number without a quote.

About

Built with its first users.

Gregory is an AI built into the model, around one problem: a forecast keeps its numbers and loses why anyone believed them. The inputs that move it scatter into emails, calls, and memory the moment the file is saved. Ask, and the answer has to come from those — or it does not come.

The daily surface is the Excel pane. It is built hands-on with a working fractional CFO practice — the cycles run against real client work before they ship. The product is in development, and access is by request while that work continues with a small group of practices.
